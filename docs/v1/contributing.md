# Contribution Guide

Dirtybase is developed in a public GitHub repository. Before opening a pull request:

1. Read the existing code and contracts for the area you are changing.
2. Keep framework behavior in the appropriate workspace package.
3. Run the relevant Cargo checks and tests.
4. Describe the behavior change and any configuration changes.

Open issues and pull requests at [github.com/kpama/dirtybase](https://github.com/kpama/dirtybase).
