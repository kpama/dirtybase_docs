# Dirtybase Documentation

Dirtybase is a battery-included Rust web framework built on Axum and SQLx. It provides the application lifecycle, HTTP routing, database tooling, authentication, and common application services needed to build a web application.

These docs are organized like the framework itself. Start with the installation guide, then follow the core concepts before choosing the areas your application needs.
